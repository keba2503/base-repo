# Security Policy

## Reporting a vulnerability

Email keba2503@gmail.com with a description of the issue, the steps to reproduce it, and its potential impact. Do not open a public issue for a suspected vulnerability.

## Response window

Expect an acknowledgement within 3 business days and a resolution plan within 10 business days. Confirmed vulnerabilities are fixed before public disclosure; the reporter is credited unless anonymity is requested.

## Supported versions

This is a base repository. Security fixes land on the `main` branch. Projects derived from this base are responsible for pulling in fixes on their own schedule.
